Tier 2 — Semantic

Dark Mode

All tokens in the Single Record Figma collection have two modes: Light and Dark. Dark mode values are designed for clinical environments with reduced ambient light. All pairs meet WCAG 2.2 AA; most meet AAA.

Implementation — Blazor & MAUI
Apply dark mode by toggling a data-theme="dark" attribute on the root element. Map each sr.color.* token to a CSS custom property and swap values per theme. In .NET MAUI, use AppThemeBinding with the same token names. The Figma Single Record variable collection exposes both Light and Dark modes — inspect a component to copy the correct token reference. Never hard-code hex values; always reference the semantic token so the correct value is resolved at runtime.
