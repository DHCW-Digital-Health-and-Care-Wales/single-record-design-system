Introduction

The Digital Health and Care Wales Data Quality team reviewed the use of each value for NHS
Number Status Indicator data item. The data demonstrated that no Local Health
Boards/Trusts are using the code ‘nn’ and haven’t since October 2019.

NHS England does not have the value ‘nn’ in their NHS Number Status Indicator data item. It
is therefore proposed to retire the value ‘nn’ as it is no longer used, this will then support
alignment with NHS England.


Description of Change

The following changes to the existing data item ‘NHS Number Status Indicator’ have been
identified:

   •   To retire value ‘nn - Number present and traced using Welsh Patient Demographic
       Service’


Data Dictionary Version

Where applicable, this DSCN reflects changes introduced by DSCN and/or DDCN since the
release of version 4.24 of the NHS Wales Data Dictionary.

The changes introduced by such DSCNs will be published in version 4.25 of the NHS Wales
Data Dictionary.

Actions Required

Local Health Boards:

   •   Ensure that local processes and systems have been updated to comply with the
       standard set out within this DSCN.

Digital Health and Care Wales:

   •   Ensure that all national systems have been updated to comply with the standard
       set out within this DSCN.
   •   Data Acquisition to update their processes to comply with the changes set out within
       this DSCN.
