Practice’ and remove the data item ‘General Medical Practitioner (Registered)’ from Outpatients

Dictionary.

                            DATASET CHANGE NOTICE (2006) 11 (W)

Reference:                     WISGSB 2007061401

Subject:                       To rename ‘Code of GP Practice (Registered GMP)’

Reason for Change:             To comply with the GMS Contract

Implementation Date:           This change should be applied from July for data submitted in
                               August and beyond.

Background:

In England DSCN 20/2004 – GMS Contract Patient Registrations introduced the new
arrangements regarding the registration of Patients with GP Practices, rather than with individual
GPs.

In Wales, WHC (2004) 008 - New GMS Project Implementation details the implementation of
the GMS Contract across NHS Wales. Further guidance was provided within WHC (2005) 044 -
New GMS Contract: Extended IM&T Guidance.

The existing minimum datasets no longer reflect the new arrangement and must be changed. All
the patient level datasets listed below should hold the Code of the practice to which the patient is
registered, as opposed to the individual GP.

This will require the following changes to the NHS Wales Data Dictionary: -
        Rename the data item ‘Code of GP Practice (Registered GMP)’ to ‘Code of
            Registered GP Practice’ and amend associated definition
        Remove the linking text ‘General Medical Practitioner (code of registered GMP) from
            Outpatients (OP mds) and Elective Admissions List (EAL mds)
        Update the OP, EAL, and Critical Care (CC) dataset layouts with revised data item

The Admitted Patient Care Dataset (APC mds) requires further work to enable the change and
this issue will be addressed in a subsequent DSCN.

The data item ‘General Medical Practitioner (Registered)’ is no longer required in the OP mds
and VAS checks on this field will be switched off for attendance dates after and including 1 st
July 2007. If there is any data submitted in this field after the changeover it will be ignored and
loaded onto the database without errors being identified.

(EAL mds/ General/ OP mds/Cancer/CC mds/OPR mds)
This is the code of the patient’s registered General Practitioner (GMP) Practice. This lets him or her
